# Feedback Loop

Use this note when the workflow repeats.

Capture after each run:

- where time was spent
- which step failed, if any
- whether a default assumption was used
- whether the failure was due to input ambiguity, data, CLI, or export
- whether the skill should be tightened before the next use

Update the skill only when the same friction shows up more than once or when the safer path is now known.
